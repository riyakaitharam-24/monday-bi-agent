# Monday.com Business Intelligence Agent

## Overview
This project implements an AI-powered Business Intelligence Agent that can answer founder-level questions using data from monday.com boards. The system analyzes sales pipeline data and work order execution data to generate insights about revenue, pipeline health, sector performance, and operational metrics.

The goal of the project is to simulate how founders and executives can quickly obtain important business insights without manually analyzing multiple datasets.

---

## Problem Statement
Business leaders often need quick answers to questions such as:

- How is our sales pipeline performing?
- What is the expected revenue this quarter?
- Which sector contributes the most to the pipeline?
- What is the current execution status of projects?

However, business data is often messy, inconsistent, and distributed across multiple boards. This project builds an AI agent that processes such data and generates meaningful insights.

---

## Data Sources
The system uses two datasets imported into monday.com boards:

### 1. Deals Board
Contains sales pipeline information such as:
- Deal owner
- Client code
- Deal value
- Closure probability
- Sector/service
- Deal stage
- Tentative close date

### 2. Work Orders Board
Contains project execution information such as:
- Customer name
- Nature of work
- Execution status
- Billing information
- Delivery dates

These datasets simulate real-world business operations data.

---

## Features

### Data Cleaning
- Handles missing values
- Converts inconsistent numeric fields
- Normalizes probability values

### Business Intelligence Metrics
The agent calculates:

- Total pipeline value
- Expected revenue based on deal probability
- Sector-wise pipeline performance
- Pipeline distribution by deal stage
- Project execution status

### Conversational Query System
Users can ask questions such as:

- "How is our pipeline looking?"
- "What is the expected revenue?"
- "Which sector is performing best?"
- "Show pipeline by deal stage."

The agent processes the query and returns relevant business insights.

### Leadership Update Generator
The system can generate automated business updates for leadership summarizing:

- Total pipeline value
- Expected revenue
- Top performing sector
- Completed projects
